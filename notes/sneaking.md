# Sneaking (World 6)

Page: `components/Sneaking/` (Sneaking.jsx = header + tabs, one file per tab, NinjaSlot.jsx = one inventory slot).
Math: `utils/sneakingUtils.js`, ported from Toolbox `parsers/world-6/sneaking.ts`. Data: `data/sneakingMap.js`,
generated by `IdleOn Resources/gen_sneaking.py <toolbox clone>` (don't hand-edit it, re-run the script).

## Save layout (extractSnapshot parseSneaking → snapshot.sneaking)
- `Ninja[i]` per character: `[floor (0-based), activity, ...]`. activity < 0 = KO'd, 0 = tied up, else working.
- `Ninja[12 + 4i .. 15 + 4i]` = character i's hat, gloves/nunchaku/kunai, charm, charm as `[rawName, level]`.
- `Ninja[60..98]` = 39 storage slots (3 rows of 13). `'Blank'` = empty.
- `Ninja[100][floor]` = damage dealt to that floor's door. `Ninja[102][1]` = Jade Coins, `[102][9]` = emporium letters.
- `Ninja[103]` = knowledge upgrade levels, `[106]` = every item ever found, `[107]` = pristine charms found.
- `OptLacc[231]` = mastery being played, `[232]` = highest mastery tier, `[233 + i]` = gemstone counters, `[402]` = charm rolls today.
- `Spelunk[14][slot]` = symbol level, `Spelunk[15]` = Funeral Flowers per floor.
- `Spelunk[13][3]` = Coral Reef upgrade 4 level ("Adds a new mini 'Ninja Knowledge' upgrade"): unlocks knowledge
  upgrades 17+ one per level, in order. The page calls them Mini Ninja Knowledge (Coral Reef).
- `Menagerie[6]` / `[7]` = Omnijade placed / Omnijade levels on knowledge upgrades 0-16.

## Symbols
Only the two charm slots of each ninja and every storage slot take a symbol (hat and gloves/weapon don't):
equipped charm slots → `Spelunk[14][2t]`, `[2t + 1]`; storage slot `60 + k` → `Spelunk[14][24 + k]`.
Slot background = `NjBorderS<LV>.png` (`.sneaking-slot--sym1..9`); each LV = +50% to the charm there.

## Numbers
- Gold charms only work from storage; their value there is × (1 + Starite%) × (1 + legend talent 6%) × (1 + symbol%).
- Gemstones: `x3 + x5 * c / (1000 + c)`, × Moissanite and Generational Gemstones (talent 432) for the other 7.
  `$` gems (Emerald) show a diminishing % `100 * (1 - 1 / (1 + bonus / 100))`. Counters cap at 10M.
  Breakpoint chips = counter-driven part at 50/75/90/99/99.9% (counter 1K/3K/9K/99K/999K).
- Emporium cost goes by display row (`getEmporiumCost`), not upgrade id. Under-construction rows are hidden.
- Doors: playing below your highest mastery opens every door. `Ninja[100]` keeps the door damage of your highest
  mastery, so header "Floors Open" and the Mastery panel use the highest mastery (game: "Reach Floor 12, Currently on N").
  Ninja status (breaching) uses the mastery being played.

Matches Toolbox (raw-save.json, Nov 2026): gemstone bonuses, every storage/equipped item value and symbol level,
all 32 knowledge levels/values/unlocks.

## Eli's layout decisions
- Header mastery box: small, sub line "Currently VII" when farming a lower mastery (not "Farming", that's the W6 skill).
- Storage: the game's 3 rows of 13; at half width the box scrolls sideways. Eli tried a wrapping grid and didn't like
  it (scrambles the game order). Full size can't fit at half width: it needs 768px, the page has 630px, and even
  everything right of the sidebar (738px) is short.
- Pristine Charms: compact 2-3 column rows (icon, name, bonus), missing ones greyed.
- Gemstones: card text is only what the gem boosts; the number shows once, in green under the bar.
- Mastery: one panel like the game's Sneak Mastery window. Shows max(8, tier) lines, so a tier past the game's
  list (none yet) gets a "No bonus here yet" line. No mastery cap found in Toolbox data; the game asks you to reach
  floor 12 for the next one.

## Detection tab
- `getNinjaStealth(snapshot, tomePoints)` = Toolbox getNinjaStealthParts/getSneakingDetection: base (10 + Way of Stealth × Sneaking LV)
  × every source, grouped This ninja (charms, Fractal) / This floor (floor mates' Smoke Bomb + Lotus Flower, Funeral Flowers
  `Spelunk[15][floor]` × knowledge 21) / Account-wide. Farming LV, star sign and statue read the played character.
- Floor difficulty = `floorBaseDifficulty` (NinjaInfo[9], gen_sneaking.py): floor 0 fixed, else 0.1 × base × last entry ^ mastery played.
- detection = 1 - 1.1 × stealth / (stealth + difficulty); 0% needs stealth ≥ 10× difficulty. `formatDetection` never rounds up to 100%.
- Stealth Chapter bubble needs Tome points (prop from App, listed in TOME_POINTS_USES).
- Matches Toolbox exactly (raw-save.json, Nov 2026, Tome 53,661): every source, stealth and detection for all 11 ninjas.
- Eli only wants current detection + breakdown, no optimizer or what-if planner.

## Setups tab
- Eli's setups (not an optimizer, he didn't want one): `data/sneakingSetups.js`, roles count 'one' or 'rest' (whoever's left).
  Chips = items the setup needs for your ninja count vs owned (equipped + storage), `getSetupPlan`.
- Item Farming is split into Stealth (Rosaries + Scroll of Power, rest 2x Lotus) and Hybrid (adds a taunter, rest Lotus + Yellow Belt).
- Taunting Mark vs 2nd Yellow Belt (Funeral Flower Push): kept the Mark. Speed only helps between KOs, the Mark cuts KO time
  and soaks the other ninjas' KOs, so it wins whenever a KO lasts longer than an action. Not checked against real KO/action times
  (no formula for those in Toolbox).
- KOs add Funeral Flowers (knowledge text "more Funeral Flowers whenever a Ninja gets KO'd"), Lotus Flower is the charm.
