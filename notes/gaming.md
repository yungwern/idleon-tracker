# Gaming (World 5)

Files: components/Gaming = Gaming.jsx (tiles, two dropdowns, tab row) + BitMultiPanel.jsx, BitSpendingPanel.jsx, ImportsTab.jsx,
SnailPlanner.jsx, SuperbitsTab.jsx, MutationsTab.jsx, LogBookTab.jsx, PaletteTab.jsx. Sidebar: World 5, before The Hole.

**Layout (Eli's picks)**: tiles = Bits (in-tier amount + Bits_<tier> sprite), Bit Multi, Sprout Value / Sprout Speed (fertilizer
LV, tooltip = effect + next LV cost), Sprout Capacity (fertilizer + gem shop; no current sprout count: late accounts fill the garden in
under a second), Envelopes, Rat Tokens, Acorns (counted on from the save), Kitsune Roxie ON/OFF. Fertilizer icons are cropped from
Toolbox data/GamingFert.png (FertValue/FertSpeed/FertCapacity.png). No Drops tile: drops show on the Little Sprinkler card.
Under the tiles: Bit Multi Sources dropdown (owned as a table, missing as one wrap of chips; weekly-vote sources like Meritocracy are
listed, dimmed when not this week, never "missing") and Spend Bits Elsewhere (no page buttons: they broke the column alignment).
Tabs: Imports (cards, then the snail planner), Superbits (one group at a time, Super first, Hide owned, no search, no page links),
Mutations, Log Book (10 x 10 grid, species name + found/crowns per row), Palette (Palette Luck dropdown, board + cards).
No notifications for Gaming (Eli). Eli turned down: time-to-afford for acorns (chemical plants give days of progress in seconds),
a garden plot view, a "what to buy" list inside Gaming, Log Book next-plant gains, starring palette colours (suggested = fastest only).

**Imports extras**: Little Sprinkler water drops (Toolbox getDropsAmount, at save time); Dirty Shovel nuggets since last upgrade
(OptLacc 192) with the Metal Detector %; Autumn Squirrel Mega Nut chance (palette 31 Red Orange); Elegant Seashell rank progress bar:
shellRankTotals in gamingMap.js = total plants evolved per rank, from the idleon.wiki Gaming page (ranks 1-45, no formula found, past
45 the card says so). The 16 GamingItem3_<n> shell sprites aren't used: which rank shows which is unknown. Snail card shows the
current encouragement's odds and points to the table.

**Superbits images**: the game has none. images/gaming/superbits/<index>.png were picked by theme from our sprites + Toolbox's
(MSA_<n> icons, Slab, Atom, Lumi, palette colours...), small ones nearest-neighbour upscaled to 40px+. 70/71 (No Way/No How) use the
bits sprite of their cost; gen_gaming.py sets `image` only for indexes that have one.

**Mutations**: the new species chance shows always (the game does too, even at 8/8), rounded down to 0.1% like the game. The "claim
often" card uses the unrounded chance: 42 × DNA / (100 + DNA) × 0.31^found (7 × ... capped 80% for the first) flattens with DNA, so
if a research attempt spends the DNA, small claims find more (two at 100 ≈ 1.5x one at 200). That DNA is spent per attempt isn't
confirmed from the save or Toolbox (Eli's 3.59M DNA at 8/8 fits it piling up once nothing is left to find).

**Math**: utils/gamingUtils.js only reads snapshot.gaming (+ legend talents, gem shop) because a dozen utils import it (superbits,
getPaletteBonus, MSA). Everything that reads other systems is in utils/gamingBonusUtils.js, imported only by the Gaming page
(avoids import cycles). Data = data/gamingMap.js, generated by `IdleOn Resources/gen_gaming.py <Toolbox clone>`
(paletteMap + odds/rgb, gamingImportMap, fertilizerMap, superbitMap, mutationMap).

**Save** (extractSnapshot parseGaming): Gaming[0] bits, [1..3] fertilizer LVs, [4] mutations, [5] DNA, [7] evolution LV, [8] best
nugget, [10] POiNG score, [11] Log Book (one save letter per row = plants found), [12] superbits, [13] envelopes, [14] rat tokens.
GamingSprout[25 + i][0] = import LV; [26][1] s since dig; [27] = [squirrel LV, s since acorn visit, acorn shop LV 1, 2]; [28] = [.., plants
evolved, shell rank]; [29] = Kitsune [bonus, on]; [30][1] Bog Log timer (ready at 80,000); [32] = [.., snail LV, encouragement];
[33] = [King Rat base %, shop LVs x3]. OptLacc 192 nuggets since upgrade, 411 100x toggle, 415 acorn shop LV 3, 497 best log round.
Spelunk[9] palette LVs, [10] selected colours, [49] black stars. Research[11] = crowns ("<row><save letter>"). serverVars
GamingFertCostExpA = Sprout Value cost growth (missing → lowest 1.13). Divinity[28 + slot] = blessing LVs (snapshot.divinity.blessingLevels).
Timers add time since TimeAway.GlobalTime (snapshot.resets.savedAt), like Toolbox's lastUpdated.

**Checked against Toolbox** (parseData on raw-save.json, Nov 2026): bit multi 5.11e71 (all 30 sources), import bonuses/costs,
fertilizer costs + sprout speed 0.296 s, King Rat (crown 1 in 2,952, 41.75 tokens/hr, shop costs), mutation cost/chance, palette
bonuses, superbit costs/totals, blessing costs. Palette Luck = Toolbox minus the Tome lore bonus (LoreEpiBon 5) until Tome points are
typed into Settings (885x vs 934x on Eli's save without them). Differences from our other helpers, matched to Toolbox:
- Gummy Orb = base × form × slab multi × floor((looted − 500) / 10); Weatherbook = base × form × played character's Gaming LV
  (sailingUtils getArtifactBonus alone only gives base × form).
- Purrmep's sprout speed bonus only counts characters linked to Purrmep (Toolbox: only Harriep/Goharut go to everyone).
- Bitty Litty = talent 177 (talentGrowthMap), × played character's Gaming LV.

**Snail**: success goes below 0 past LV 48 (−1.17% at LV 49 on Eli's save = Toolbox); shown negative like the game (the dev's
way of holding the snail at 49). Reset/nothing use it as 0. Reset only rolls on a failed attempt,
so per attempt: up = success, reset = (1 − success) × reset chance, nothing = the rest. "Up before reset" = success / (success + reset).
Hole schematic 53 = +4% success per power of 10 of Well sediment 13. Planner lets you type another LV.

**Palette**: odds = luck / (x6 × max(1.2, x7 − 0.05)^LV); locked colours touching an owned one = luck / x8 (adjacency table in
gamingUtils). Suggested slots = the fastest colours to level, one per selected slot. Hidden caps (9 with Bog Log 75%, 16 with
Golden Sprinkler 82%, 17 with exotic 46 100%) only stop that colour's own bonus: capped colours still get suggested (Eli: every LV
still counts toward total palette LVs, e.g. Colourful Luck). Capped hexes are striped (no text: a CAP tag didn't fit the hex), legend swatch + tooltip explain it. Black Stars = BlackStar.png left of
the LV (and right for 2). Palette Luck = its own dropdown (multipliers, then the added luck bonuses). Board positions = the game's
palette screen formula (PALETTE_HEX_POSITIONS).

**Spend Bits Elsewhere**: Divinity blessings for Snehebatu, Nobisect, Goharut, Kattlekruk (slots 0/2/4/8, Toolbox getGodCost: next LV =
x4 × x5^LV, max LV = 100 + coral kid 1 + minehead 9 + vault 76 + jellies 49/63), and The Bell's bits improvement method (holeCavernUtils
getBell methods[2]). Toolbox knows no other bit costs; add new ones to getBitSpending.
